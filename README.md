# CN5006 Week 5: Express REST API

Express app with REST API routes (GET, POST, PUT, DELETE) that call the MongoDB functions from Week4lab.js using Mongoose.

To run it:

```
npm install
node index.js
```

Then open http://localhost:5001. It uses port 5001 because port 5000 is taken by AirPlay Receiver on my Mac. MongoDB needs to be running on localhost:27017 (database: Employee).
